# **Multi-Source SaaS Revenue & Customer 360**

Northstar is a subscription-based software company operating with data trapped across isolated systems—including billing, product usage, payment logs, and support records. When Finance, Sales, Product, and Customer Success departments pull from separate silos, they rely on conflicting logic to define active customers and recurring revenue. This fragmented architecture prevents management from answering fundamental questions regarding retention, churn, and overall customer health. This project implements an end-to-end analytics engineering solution built on synthetic multi-source data to establish a trusted, unified source of truth. 

> [!IMPORTANT] 
> This project uses synthetic data inspired by publicly available product concepts. I do not claim to have access to the internal data or architecture of any real company. I use approved, public, anonymized, or explicitly synthetic data to demonstrate how as an analytics engineer I can resolve cross-departmental discrepancies from siloed data by building a trustworthy analytics foundation. 

My objective is to execute on two analytical tracks:
- Analytics Engineering — Ingest, transform, and dimensionally model the disparate raw sources.
- Data Analysis — Leverage the modeled foundation to provide data-driven business recommendations.

## Core Business Questions
- How many active customers do we have each month?
- How is monthly recurring revenue (MRR) changing?
- Which customer cohorts retain best?
- Where is churn or revenue contraction concentrated?
- Does product usage differ between retained and churned customers?
- Which plans or customer segments create the most support burden?
- How much revenue is affected by refunds or failed payments?
